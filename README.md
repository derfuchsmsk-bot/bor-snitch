# Bor Snitch Bot 🏆🐀

**Твой персональный циничный судья, который следит за каждым твоим словом.**

Bor Snitch — это Telegram-бот с искусственным интеллектом (Gemini AI), который анализирует переписку в чате, выявляет нытиков, токсиков и крыс, и безжалостно раздает им по заслугам.

> *«В этом чате нет невиновных. Есть только те, кто еще не попался.»*

---

## 🚔 Как это работает

Бот читает все сообщения в чате.
Раз в сутки (или по мгновенному доносу) AI анализирует поведение участников и начисляет **Snitch Points** (Очки Снитча).

### 📋 Кодекс Снитча (Классификация грехов)

За каждый проступок начисляются очки. Чем больше очков — тем хуже твое положение (или лучше, если ты стремишься на дно).

| Грех | Очки | Описание |
| :--- | :--- | :--- |
| **Нытье (Whining)** | **0** | Жалобы на жизнь, работу, погоду. "Ой, я устал", "Ой, всё плохо". *(Временно отключено)* |
| **Духота (Stiffness)** | **0** | Занудство, придирки к словам, пассивная агрессия. *(Временно отключено)* |
| **Токсичность (Toxicity)** | **20** | Грубость, агрессия, оскорбления (УЧАСТНИКОВ, а не бота). |
| **Снитчевание (Snitching)** | **40** | Игнор, предательство, нарушение договоренностей. Высшая мера. |
| **AFK (Молчанка)** | **30+** | Молчание от 3-х дней. Прогрессивная шкала (30 + 30 за каждый следующий день). |

### 🛡️ Иммунитет и Нюансы
*   **Контекст — король.** Дружеская перепалка (roasting) не карается.
*   **Оскорбление Бота.** Разрешено. Бот выше этого. Можете называть его как угодно, очков не дадут.
*   **Факты.** Бот судит по фактам, а не по догадкам.
*   **Стикеры.** Бот теперь видит ваши стикеры. Осторожнее с клоунами 🤡.
*   **Циничный Комментатор.** Бот иногда может вставить свое едкое слово в ваш разговор (шанс 0.2%).

## 👑 Иерархия (Ранги)

Мы используем ироничную тюремную кастовую систему. Чем больше ты грешишь, тем "выше" твой ранг в мире снитчей.

| Очки | Звание | Статус |
| :--- | :--- | :--- |
| **0 - 49** | **Порядочный** 😐 | Пока держишься. Молчишь в тряпочку. |
| **50 - 249** | **Шнырь** 🧹 | Начал прогибаться. Пара косяков или одна победа. |
| **250 - 499** | **Козёл** 🐐 | Активный стукач. Сотрудничаешь с администрацией. |
| **500 - 999** | **Обиженный** 🚽 | Твое место у параши, но ты всё равно пишешь. |
| **1000+** | **Масть Проткнутая** 👑 | Элита дна. Король крыс. |

## 🧹 Еженедельная Амнистия

В этом чате нет пожизненных сроков, но нет и полного обнуления.
**Каждое воскресенье в 23:59** проводится амнистия:
*   Очки, набранные **за прошедшую неделю**, делятся на два и вычитаются из общего счета.
*   Это позволяет "смывать" свежие косяки, но старые грехи (накопленные за месяцы) остаются с вами надолго.

## 🎮 Команды

*   `/status` (или `/me`) — Показать твое личное дело: Звание, Очки, Победы.
    *   *Лайфхак:* Ответь этой командой на сообщение друга, чтобы узнать его масть.
*   `/stats` — Таблица лидеров. Кто главный кандидат на "Масть Проткнутую"?
*   `/report` (в ответ на сообщение) — **МГНОВЕННЫЙ ДОНОС**.
    *   Видишь нытье или духоту? Жми `/report`.
    *   AI проверит сообщение (текст, стикеры, контекст 25 сообщений).
*   `/casino` — Испытать удачу. Можно списать 50 очков или огрести +60.
*   `/remember` — Запомнить факт о пользователе (для Lore).
*   `/all` — Позвать всех участников чата.
*   *(Если включено)* `/agreements` — Список договоренностей.
*   *(Если включено)* `/dispute` — Оспорить договоренность.
*   `/rules` — Показать правила и расценки на грехи.
*   `/start` — Активировать бота (если он уснул).

## 🛠 Техническая часть (для админов)

*   **Stack:** Python 3.11+, FastAPI, Aiogram 3, Google Firestore.
*   **AI:** Vertex AI (Gemini 3 Flash Preview).
*   **Hosting:** Google Cloud Run.

### Быстрый старт
Подробная инструкция по установке: [setup.md](setup.md)

1.  Клонируйте репо.
2.  Настройте `.env`.
3.  Задеплойте в Cloud Run.
4.  Настройте Cloud Scheduler для эндпоинтов `/analyze_daily` и `/weekly_decay`.
