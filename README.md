> *«В этом чате нет невиновных. Есть только те, кто еще не попался.»*

**Bor Snitch** — это продвинутый Telegram-бот с искусственным интеллектом (Google Gemini), встроенным голосовым радиовещанием (ElevenLabs), системой отслеживания пацанских договоренностей и собственной веб-панелью управления (CMS). Бот круглосуточно следит за атмосферой чата, наказывает токсиков и крыс, ведет хронику событий компании и озвучивает ежедневные криминальные подкасты.

---

## ⚡ Ключевые возможности

### ⚖️ 1. AI-Судья и Кодекс Снитча
Бот анализирует переписку, выявляет нарушения и начисляет **Snitch Points**:
* **Токсичность (25 очков):** грубость, неоправданная агрессия и оскорбления участников.
* **Снитчевание и Игнор (50 очков):** намеренный игнор прямых вопросов, слив инфы, предательство.
* **AFK (Молчанка 50+ очков):** прогрессивная шкала за молчание от 3-х дней.
* **Нытье и Духота:** детекция жалоб и занудства.
* **Штраф за клевету (15 очков):** наказание за необоснованный донос через `/report`.

### 👑 2. Кастовая система (Ранги)
Ироничная кастовая иерархия по набранным очкам:
* **0 – 49 очков:** `Порядочный 😐` — пока держится, образцовый гражданин.
* **50 – 249 очков:** `Шнырь 🧹` — первые косяки или случайная победа.
* **250 – 499 очков:** `Козёл 🐐` — активное сотрудничество с администрацией.
* **500 – 999 очков:** `Обиженный 🚽` — пора задуматься над поведением.
* **1000+ очков:** `Масть Проткнутая 👑` — абсолютная элита дна.

### 🎙️ 3. Ежедневное Радио (Voice Digest via ElevenLabs)
Бот выпускает настоящее аудио-шоу — 45–60 секундный голосовой выпуск в Telegram:
* **Расписание:** дважды в день через Google Cloud Scheduler:
  * **14:00 МСК** — *Обеденная хроника* (утренние косяки, обсуждения, планы, мемы);
  * **22:00 МСК** — *Вечерний приговор* (итоги дня, Снитч дня, очки и статус договоренностей).
* **По требованию:** в любой момент командой `/digest` в чате или кнопкой в CMS.
* **Технология:** сценарий пишет Gemini, а озвучивает нейросеть **ElevenLabs** (голос Adam, модель `eleven_multilingual_v2`) в нативном формате Telegram Voice без дублирования текстом.

### 🤝 4. «Слово Пацана» (Модуль договоренностей)
AI на лету фиксирует публичные обещания участников (*«обещаю», «договорились», «пойду на фильм»*):
* **Адаптация под контекст:** если кто-то присоединяется к обещанию или встреча переносится по обоюдному согласию — бот автоматически обновляет карточку договоренности.
* **Окно оспаривания:** 15 минут на отмену шуточного обещания командой `/dispute`.
* **Штраф за нарушение:** нарушение зафиксированной договоренности = 50 очков за Снитчевание.

### 🎭 5. Циничные эмодзи-реакции
Бот автоматически и к месту ставит реакции на сообщения (с защитой от спама и кулдауном):
* **🤡** — на нытье, духоту и кринж;
* **🚽** — на сообщения от нарушителей высоких рангов;
* **🍿 / 👀** — на споры, обвинения и доносы;
* **🗿 / 👑** — на пацанские цитаты, базу и договоренности;
* **🔥** — на мемы и стикеры.

### 🧹 6. Еженедельная Амнистия
Каждое воскресенье в **23:59 МСК** очки, набранные за прошедшую неделю, **делятся пополам** и списываются с общего счета. Старые накопленные грехи остаются, но свежие косяки смываются.

## 🎛️ Веб-панель управления (Admin CMS)

Сервис оснащен встроенной веб-панелью по адресу `https://<твой-домен>/admin`. 
Все изменения вступают в силу **мгновенно без перезапуска и передеплоя бота**:

* **🔐 Авторизация:** защищенный вход по паролю (`ADMIN_PASSWORD` в `.env`).
* **⚙️ Настройки бота на лету:**
  * Master-switch включения/выключения бота;
  * Тарифная сетка очков (токсичность, игнор, AFK);
  * Параметры казино (шанс победы, размер выигрыша/проигрыша);
  * Настройка шанса циничных комментариев и эмодзи-реакций;
  * Управление часами выхода радио-выпусков (14:00 / 22:00) и движком TTS (ElevenLabs / Google).
* **🧠 Студия промптов (Prompt Studio):**
  * Полноэкранный редактор всех 7 системных промптов Gemini с подсветкой переменных (`{lore_json}`, `{current_context}`, `{active_agreements}`);
  * Кнопка «Сбросить к оригиналу» для безопасных экспериментов.
* **👥 Участники и База данных:**
  * Список пользователей чата, кастовые ранги, баланс очков;
  * Кнопки быстрого начисления/списания (+25, -25, произвольно) с причиной;
  * **Аудит начислений (Ledger):** просмотр истории и откат ошибочных штрафов в 1 клик;
  * Выдача и редактирование ачивок.
* **📜 Лор и Факты:**
  * Управление проверенными фактами о людях;
  * Прямой редактор JSON-ядра лора (персонажи, концепции, словарь сленга).
* **⚡ Действия в 1 клик:**
  * Запуск дневного анализа чата;
  * Применение еженедельной амнистии;
  * Сканирование договоренностей за прошедшие 7 дней;
  * Генерация голосового радио-выпуска;
  * Консоль выполнения логов в реальном времени.

## 🎮 Команды бота

| Команда | Описание |
| :--- | :--- |
| `/status` (или `/me`) | Личное дело: звание, очки, победы, список ачивок (работает и в реплай) |
| `/stats` | Таблица лидеров и кандидатов на «Масть Проткнутую» |
| `/digest` (или `/voice`) | 🎙️ Экстренный голосовой радио-выпуск новостей чата (ElevenLabs) |
| `/report` *(в ответ на сообщение)* | **Мгновенный донос:** AI проверит сообщение с учетом контекста диалога |
| `/casino` | Испытать удачу: списать 50 очков или огрести +60 |
| `/agreements` | Список действующих договоренностей («Слово Пацана») |
| `/dispute` *(номер)* | Оспорить зафиксированное обещание в течение 15 минут |
| `/remember` *(текст)* | Добавить исторический факт об участнике в Lore |
| `/rules` | Показать Кодекс Снитча и расценки на грехи |
| `/all` | Позвать всех участников чата |
| `/start` | Активация бота в чате |
| `/bot_disable` / `/bot_enable` | Отключение/включение бота (Admin) |

## 🛠 Архитектура и Стек

* **Язык & Фреймворк:** Python 3.11+, FastAPI, Uvicorn.
* **Telegram движок:** Aiogram 3.x (Webhooks).
* **Искусственный интеллект:** Google Cloud Vertex AI (Gemini Flash Preview).
* **Голосовой синтез:** ElevenLabs API (`eleven_multilingual_v2`, голос Adam) + Google Cloud Text-to-Speech (OGG_OPUS / MP3).
* **База данных:** Google Cloud Firestore (NoSQL, распределенные транзакции).
* **Хостинг:** Google Cloud Run (Serverless контейнеризация с 2GB RAM / 2 vCPU).
* **Автоматизация:** Google Cloud Scheduler (ежедневные cron-задачи).
* **Frontend админки:** SPA на Tailwind CSS + JavaScript (встроено в сервис).

## 🚀 Быстрый старт

### 1. Клонирование и установка
```bash
git clone https://github.com/derfuchsmsk-bot/bor-snitch.git
cd bor-snitch
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```

Заполните переменные:
```ini
TELEGRAM_TOKEN=123456:ABC-DEF...
WEBHOOK_URL=https://your-service.run.app
GCP_PROJECT_ID=your-gcp-project-id
GCP_LOCATION=global
SECRET_TOKEN=your-webhook-secret
ADMIN_PASSWORD=your-super-admin-password
JWT_SECRET=your-32-chars-jwt-secret-string
ELEVENLABS_API_KEY=your-elevenlabs-key
MAIN_CHAT_ID=-100123456789
```

### 3. Запуск тестов
```bash
pytest
```

### 4. Деплой в Google Cloud Run
Сервис автоматически деплоится через Cloud Build при пуше в ветку `main`, либо вручную:
```bash
gcloud run deploy bor-snitch \
  --source . \
  --region europe-west1 \
  --memory 2Gi \
  --cpu 2 \
  --no-cpu-throttling \
  --allow-unauthenticated
```
