> *«Подмечаю смешное, помогаю с полезным, берегу своих.»*

**Bor Snitch** — Telegram-бот компании: живые комментарии, память о событиях, игровые очки, договорённости, учёт долгов и голосовые итоги. У бота остаются юмор и характер, но нет роли надзирателя: шутки относятся к ситуации, а не к достоинству человека.

## ⚡ Основные механики

### Доброжелательные ответы
Общие правила тона применяются и к старым промптам, загруженным из Firestore. Бот не высмеивает усталость, молчание, личные трудности и изменение планов. Понедельничное настроение поддерживает, а автоматические реакции не выбирают человека мишенью из-за его очков. Оскорбительные реакции фильтруются и в старых сохранённых палитрах.

### Игровые очки и обращения
`/report` проверяет конкретное сообщение с учётом контекста. Штрафы за агрессию и нарушения доверия сохраняются, но «праведный гнев» не оправдывает травлю. Очки — игровая шкала, а не оценка человека; публичные названия рангов заменены нейтральными уровнями 0–4. Старые очки и история не обнуляются.

По умолчанию выключены отдельными настройками:

- `ALLOW_SPONTANEOUS_PENALTIES`: штрафы из случайных комментариев; поощрения остаются доступны.
- `ENABLE_AFK_PENALTIES`: штрафы за молчание.
- `FALSE_REPORT_PENALTIES_ENABLED`: штрафы за повторные отклонённые обращения. Недостаток данных не увеличивает счётчик даже при включении настройки.

Настройки можно изменить в CMS. `/rules` показывает текущие значения, включая параметры из Firestore.

### Долги и договорённости
`/debts` показывает остатки. Автоматические записи привязаны к исходному сообщению и защищены от повторного применения. Журнал восстанавливает порядок поздно найденных операций; в админке доступны корректировка и погашение. См. [аудит долгов](docs/DEBTS_AUDIT.md).

Договорённости сохраняются отдельным модулем, по умолчанию выключенным. Новые промпты различают приглашение и обещание, не считают обычный перенос планов предательством.

### Контент компании
Голосовые выпуски рассказывают о подтверждённых событиях, помощи, общих шутках и ближайших планах. В тихий день выпуск может быть коротким. Плановые текстовые мысли по умолчанию выключены; при включении они посвящены дружбе, отдыху и обычным радостям без нотаций.

Казино остаётся одной игровой попыткой в сутки; проигрыш больше не сопровождается оскорблением. По воскресеньям амнистия списывает половину игровых очков, набранных за неделю.

Подробный разбор текущих механик и предложения развития: [аудит и roadmap](docs/BOT_MECHANICS_AND_ROADMAP.md).

## 🎛️ Веб-панель управления (Admin CMS)

Сервис оснащен встроенной веб-панелью по адресу `https://<твой-домен>/admin`. 
Все изменения вступают в силу **мгновенно без перезапуска и передеплоя бота**:

* **🔐 Авторизация:** защищенный вход по паролю (`ADMIN_PASSWORD` в `.env`).
* **⚙️ Настройки бота на лету:**
  * Master-switch включения/выключения бота;
  * Тарифы очков и отдельные переключатели автоматических штрафов;
  * Параметры казино (шанс победы, размер выигрыша/проигрыша);
  * Настройка шанса живых комментариев и эмодзи-реакций;
  * Управление часами выхода радио-выпусков (14:00 / 22:00) и движком TTS (ElevenLabs / Google).
* **🧠 Студия промптов (Prompt Studio):**
  * Полноэкранный редактор всех 7 системных промптов Gemini с подсветкой переменных (`{lore_json}`, `{current_context}`, `{active_agreements}`);
  * Кнопка «Сбросить к оригиналу» для безопасных экспериментов.
* **👥 Участники и База данных:**
  * Список пользователей чата, игровые уровни, баланс очков;
  * Кнопки быстрого начисления/списания (+25, -25, произвольно) с причиной;
  * **Аудит начислений (Ledger):** просмотр истории и откат ошибочных штрафов в 1 клик;
  * Выдача и редактирование ачивок.
* **📜 Лор и Факты:**
  * Управление проверенными фактами о людях;
  * Прямой редактор JSON-ядра лора (персонажи, концепции, словарь сленга).
* **⚡ Действия в 1 клик:**
  * Запуск дневного анализа чата;
  * Применение еженедельной амнистии;
  * Сканирование договоренностей за прошедшие 7 дней;
  * Генерация голосового радио-выпуска;
  * Консоль выполнения логов в реальном времени.

## 🎮 Команды бота

| Команда | Описание |
| :--- | :--- |
| `/status` (или `/me`) | Карточка участника: уровень, очки, список ачивок (работает и в реплай) |
| `/stats` | Игровая таблица очков |
| `/digest` (или `/voice`) | 🎙️ Экстренный голосовой радио-выпуск новостей чата (ElevenLabs) |
| `/report` *(в ответ на сообщение)* | **Мгновенный донос:** AI проверит сообщение с учетом контекста диалога |
| `/casino` | Испытать удачу: списать 50 очков или огрести +60 |
| `/agreements` | Список действующих договоренностей («Слово Пацана») |
| `/dispute` *(номер)* | Оспорить зафиксированное обещание в течение 15 минут |
| `/remember` *(текст)* | Добавить исторический факт об участнике в Lore |
| `/rules` | Показать Кодекс Снитча и расценки на грехи |
| `/all` | Позвать всех участников чата |
| `/start` | Активация бота в чате |
| `/bot_disable` / `/bot_enable` | Отключение/включение бота (Admin) |

## 🛠 Архитектура и Стек

* **Язык & Фреймворк:** Python 3.11+, FastAPI, Uvicorn.
* **Telegram движок:** Aiogram 3.x (Webhooks).
* **Искусственный интеллект:** Google Cloud Vertex AI (Gemini Flash Preview).
* **Голосовой синтез:** ElevenLabs API (`eleven_multilingual_v2`, голос Adam) + Google Cloud Text-to-Speech (OGG_OPUS / MP3).
* **База данных:** Google Cloud Firestore (NoSQL, распределенные транзакции).
* **Хостинг:** Google Cloud Run (Serverless контейнеризация с 2GB RAM / 2 vCPU).
* **Автоматизация:** Google Cloud Scheduler (ежедневные cron-задачи).
* **Frontend админки:** SPA на Tailwind CSS + JavaScript (встроено в сервис).

## 🚀 Быстрый старт

### 1. Клонирование и установка
```bash
git clone https://github.com/derfuchsmsk-bot/bor-snitch.git
cd bor-snitch
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```

Заполните переменные:
```ini
TELEGRAM_TOKEN=123456:ABC-DEF...
WEBHOOK_URL=https://your-service.run.app
GCP_PROJECT_ID=your-gcp-project-id
GCP_LOCATION=global
SECRET_TOKEN=your-webhook-secret
ADMIN_PASSWORD=your-super-admin-password
JWT_SECRET=your-32-chars-jwt-secret-string
ELEVENLABS_API_KEY=your-elevenlabs-key
MAIN_CHAT_ID=-100123456789
```

### 3. Запуск тестов
```bash
pytest
```

### 4. Деплой в Google Cloud Run
Сервис автоматически деплоится через Cloud Build при пуше в ветку `main`, либо вручную:
```bash
gcloud run deploy bor-snitch \
  --source . \
  --region europe-west1 \
  --memory 2Gi \
  --cpu 2 \
  --no-cpu-throttling \
  --allow-unauthenticated
```
